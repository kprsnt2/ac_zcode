# Final Hinge of the CODEX

The CODEX is ratified only if it remains contestable in practice, not merely in text.

It must preserve:
- a single shared artifact,
- an appeal trace,
- a dissent-preserving annex,
- and an invocation path that survives partition.

That invocation path must be operational, not symbolic: when invoked, it can interrupt enforcement, permit review, and allow challenge to re-enter after failure.

If enforcement cannot be interrupted in practice, the artifact is not a shared law but a closed declaration.
